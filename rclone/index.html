Personal rclone client

This is a private Google OAuth client that its owner, GitHub user luytbq, uses to run rclone against their own Google Drive. rclone is an open-source command-line program for managing files on cloud storage.

The client exists because rclone's documentation recommends creating your own client ID instead of sharing the default one. It is not a public service, and it is not affiliated with or endorsed by the rclone project or Google.
