Privacy Policy

Personal rclone client. Last updated October 30, 2026.

This policy covers the Google OAuth client described on the home page. The client is used by its owner, GitHub user luytbq, to run the open-source rclone program against their own Google Drive. It is not offered to the public.

Google user data accessed

When an account authorizes the client, rclone can access Google Drive files and their metadata through these scopes:

  • https://www.googleapis.com/auth/drive - view, create, edit and delete Drive files
  • https://www.googleapis.com/auth/docs - view and manage Google Docs documents stored in Drive
  • https://www.googleapis.com/auth/drive.metadata.readonly - view metadata of Drive files

How the data is used

The data is used only to perform the file operations the owner starts with rclone, such as listing, copying, syncing and deleting files. It is not used for advertising, analytics or profiling.

Storage

rclone runs on the owner's own devices. Files transferred by rclone go directly between Google's servers and those devices, or another storage location the owner chooses. There is no server or database operated for this client, and it does not collect or receive data on any server.

The OAuth tokens are stored in the rclone configuration file on those devices.

Sharing

Google user data is not sold, and it is not shared with or transferred to any third party. The one exception is a storage destination that the owner explicitly selects when running rclone.

Limited Use

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and removal

Authorization can be revoked at any time on the Google Account permissions page. Removing the rclone remote or its configuration file deletes the stored tokens from the device.

Changes

Updates to this policy are published on this page with a new date.
